# Python OOP – Classes and Objects

## Overview
This lesson introduces the fundamentals of Object-Oriented Programming (OOP) in Python using a simple Patient Management example.

## Concepts Covered

1. **Class:** Creating a class named `patient`.
2. **Constructor (`__init__`):** Initialising objects with patient details.
3. **self keyword:** Accessing the attributes of the current object.
4. **Attributes:** Storing patient information such as name and age.
5. **Methods:** Defining `display_detail()` to display patient information.
6. **Objects:** Creating multiple patient objects from a single class.

## Code Implementation

The program defines a `patient` class with:
- `name` – Patient's name.
- `age` – Patient's age.
- `display_detail()` – Displays patient information.

Two objects are created:
- Patient 1: Rachel, 25
- Patient 2: Monica, 30

## Expected Output

```text
patient Name: Rachel
patient Age: 25
patient Name: Monica
patient Age: 30
```

## How to Run

Make sure Python is installed.

Run the following command in the terminal:

```bash
python Lesson4.py
```

## Learning Outcome

Understood how to create classes and objects, initialise attributes using constructors, use the `self` keyword, and call methods in Python.
